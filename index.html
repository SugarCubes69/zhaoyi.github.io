Projects

Multi-agent Research System

I have been wondering how the multi-agent systems were built for research tasks, such as the deep research function provided by the companies like Anthropic or OpenAI. After studying a lot of references, I decided to kickstart this project in order to understand the internal architecture and workflow of multi-agent research systems.

In my current Version 1 code: When a user submits a query, (1) the manager agent analyzes it, plans research steps, and then delegates to subagents to explore the various steps. (2) The subagents search across the web by iteratively generating Python code to call the search tools, and (3) then returning a list of gathered information to the manager agent so it can compile a final answer.
